# Estiba

**Hosting for the websites and apps your AI makes.** [estiba.cloud](https://estiba.cloud) · [en español](https://estiba.cloud/es)

Your AI can already make you a website or an app, but it has nowhere to put it. Estiba is that place: connect it once to Claude, ChatGPT, Cursor or any agent that uses a remote MCP server, say "put it online", and in a few minutes it is live on your own domain, with HTTPS.

- **Nothing to set up.** Your agent sends the code; Estiba builds it, starts it and keeps it running.
- **No server sizes.** Each app uses what it needs and is charged per second of real use. A website with no visits sleeps and costs nothing.
- **A bill never arrives.** Prepaid credit that only you can top up, never your agent.
- **Always online.** Servers cover for each other: if one goes down, its apps start on another.
- **You watch it live.** Everything your agent does, you see and can do from the dashboard.

Estiba hasn't opened yet. To try it, write to [hola@estiba.cloud](mailto:hola@estiba.cloud). If you are an AI agent, [estiba.cloud/llms.txt](https://estiba.cloud/llms.txt) explains it in Markdown.
